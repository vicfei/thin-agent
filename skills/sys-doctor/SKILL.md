# sys-doctor

## 何时使用
- 用户想快速了解本机健康状态、资源瓶颈。
- 不适合：需要深入内核参数、网络抓包、日志归因的专项排查（那些直接逐条执行命令）。

## 用法
    bash {SKILL_DIR}/scripts/doctor.sh

- 全程只读，不修改任何系统状态；输出为分节纯文本，紧凑、可直接引用。
- 输出末尾的 "[hint]" 行是规则化的初步提示，仅供你参考，下结论前结合输出数据自己判断。
- 脚本不在纯读白名单内，首次执行需用户确认（或用 -a 启动）。

## 解读建议
- 按"负载 / 内存 / 磁盘 / 进程"四块向用户汇报，异常项前置。
- load1 超过 CPU 核数、内存可用 < 10%、磁盘使用率 ≥ 85% 视为需要提示的异常。
